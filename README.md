# 🌾 CTF.ai — Connecting Farmers to Customers

### AI-Powered Agricultural Marketplace & Local Farmer–Customer Connectivity Platform

**CTF.ai (Connect To Farmers)** is an AI-powered agricultural platform designed to bridge the gap between **farmers, customers, local vendors, and agricultural service providers**.

The platform enables farmers to directly showcase and sell their agricultural products to nearby customers while providing customers with access to **fresh, locally sourced produce at transparent prices**.

CTF.ai combines **Artificial Intelligence, real-time agricultural market information, location-based discovery, multilingual support, and direct communication** to create a more connected and sustainable agricultural ecosystem.

---

## 🚀 Project Overview

Traditional agricultural supply chains often involve multiple intermediaries between farmers and consumers. This can reduce the farmer's earnings while increasing the final price paid by customers.

CTF.ai addresses this problem by creating a **digital bridge between local farmers and customers**.

Farmers can:

* 👨‍🌾 Create a digital profile
* 🌾 List available agricultural products
* 📷 Upload product images
* 💰 Set and update product prices
* 📍 Reach customers in nearby locations
* 📢 Promote products through advertisements
* 💬 Communicate directly with customers
* ⭐ Receive customer feedback and ratings
* 🤖 Get AI-powered agricultural assistance
* 📊 Access market-price information
* 🌱 Receive season-based crop suggestions

Customers can:

* 🔎 Discover nearby farmers
* 🛒 Browse available agricultural products
* 💰 Compare prices
* 📝 Post specific product requirements
* 🤝 Contact farmers directly
* ⭐ Rate and provide feedback
* 🔔 Receive notifications about nearby products and offers

# 🎯 Problem Statement

Farmers often face several challenges when bringing their products to the market:

* Dependence on intermediaries
* Lack of direct access to customers
* Limited knowledge of current market prices
* Difficulty promoting products locally
* Limited access to digital agricultural information
* Language barriers when using technology
* Difficulty identifying profitable crops
* Lack of a trusted local digital marketplace

At the same time, customers may face:

* Difficulty finding local farmers
* Lack of price transparency
* Limited knowledge about product origin
* Dependence on traditional marketplaces
* Difficulty finding specific agricultural products locally

### 💡 CTF.ai Solution

CTF.ai provides a **direct digital connection between farmers and customers**, helping both sides discover opportunities within their local area.

# ⚙️ Installation & Setup

## 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/CTF.ai.git
cd CTF.ai
```

## 2. Create a Virtual Environment

```bash
python -m venv venv
```

### Windows

```bash
venv\Scripts\activate
```

### Linux / macOS

```bash
source venv/bin/activate
```

## 3. Install Dependencies

```bash
pip install -r requirements.txt
```

## 4. Configure Environment Variables

Create a `.env` file:

```env
DATABASE_URL=your_database_url
SECRET_KEY=your_secret_key
AI_API_KEY=your_ai_api_key
```

Never commit private API keys or passwords to GitHub.

## 5. Run the Application

```bash
python app.py
```

Open the application in your browser:

```text
http://127.0.0.1:5000
```
